# Harness 升级实施记录

[English](harness-upgrade.md) | 简体中文

用于持续落实 2026-11-12 架构评估。这是接续清单，不代表报告已经全部实现。保留 Rust 运行时、SQLite、人类控制授权与自动生成协议。

## 已实现并有回归测试

- 工具批次执行前记录意图；持久化失败则停止，未知结果的批次暂停核对，不自动重放。
- checkpoint 与接续保存稳定轮次身份，按累计水位原子更新任务/run 总额；记账失败停止任务。旧断点若已有记账且缺少轮次身份，先等待核对。
- 按 checkpoint 关联的 run 找回任务；新建与恢复共用记账、预算、验收和目标驱动器，恢复后可在已授权轮数内继续推进。
- 后台作业使用跨进程随机身份；先写意图再启动进程，台账失败阻止启动。
- 作业先收集输出再公布完成；限时等待读取管道，无法读完时明确标记。作业绑定确切 task/run，结果、任务事件与已请求投递记录原子提交。
- 持久保存确切作业依赖，正常完成后接续已授权任务，重启后可恢复；人工暂停、取消优先，中断或被停止的作业等待核对，竞争唤醒只领取一次。
- 原子领取后续指令，结果落盘前保留原记录；重启时保留未知结果并写对话提示；并发领取不会重复取走同一条。
- 中文技能使用不同相邻汉字双字组合匹配，保留英文和显式调用限制。
- 快速聊天带上本会话近期对话与 SOUL，不带入其他会话内容。
- MCP 断线后重建连接，但不自动重放远端结果未知的调用。
- 长期目标跨轮延续操作编号，避免后续操作被错误去重。
- 过短工具预览优先保留可用的完整输出路径。
- 已配置的完成通知先持久化、再发送，失败后周期性及重启重试，确认成功才删除；批准提示不重放，网络错误不泄露 webhook 凭据。

## 仍需完成，按顺序推进

1. 扩展观察、记账、最终落盘之间的故障注入覆盖。崩溃前未记录的活动时长仍是近似值，不是硬实时预算。
2. 结构化交接已从持久化任务合同、计划、步骤与交付物重建；继续补领域证据版本和已核对外部回执。普通聊天自动接续仍在任务驱动器之前单独处理。
3. 持久等待现覆盖后台作业和一个人工声明的外部输入，支持重启与持久化人工暂停优先。后续领域事件适配须先明确鉴权与核对合同。定时任务及目标/任务状态已原子生成结算和投递记录。
4. 逐操作状态与人工核对已覆盖任务和普通聊天。继续补服务端幂等键，必须先明确重放合同；任意外部操作仍不保证恰好执行一次。
5. 文件验收已有带摘要校验的版本证据并绑定完成回执，未核验产出单独标记。继续补领域检查与远端读回回执；文件版本不证明领域事实正确。
6. 独立任务、本会话进度投影、数据库执行所有权及协作运行时修改协调已实现。继续加强关系连续性和按冲突范围协调资源；快答现有有限近期上下文和已存个人偏好，关系支持质量仍需评测。
7. 已实现记忆抑制/更正关系（0032）、提炼上下文（0039）与人工有效期（0040）。已补来源绑定的临时状态分类与过期（0041），继续补分类质量验证和历史元数据审查；语义改写、迁移前删除和事件历史脱敏仍未覆盖。任务交接保持独立于滚动摘要。
8. 原生 Responses 已支持文本、图片、函数工具、SSE 和本地加密接续。模型能力/推理力度配置已实现，继续补真实模型验证与自动能力探测；托管工具、WebSocket 引导、API 异步工具暂不支持。
9. 添加故障注入与固定预算真实模型评测，报告完成率、虚假完成率、重复副作用、恢复率及成本；确定性检查不能证明真实事务可靠。

## 验证

集成后执行完整 `just check`。投递与崩溃边界使用本地模拟服务，测试时不访问配置中的真实外部端点。真实模型评测须明确评测配置与成本上限，报告真实样本数和费用。

## 2026-11-13 接续进展

- 完整不可变计划与可读步骤原子提交，重启和后续目标轮次恢复同一版本；旧零散步骤不冒充完整计划。
- 工具成功次数验收限定本次 run；输出截断、迭代耗尽或未知副作用不能虚报完成。MCP 未知结果停止剩余工具及模型续跑，保留意图等待核对。
- 原生 Responses 保留加密接续，DeepSeek Chat 保留思考接续。
- 按用户授权使用 `ds` / `deepseek-flash` 运行限额真实评测；三个复核场景通过。两轮高峰价用量估算 ¥0.063274，保守预留合计 ¥1.523568，低于 ¥10。详见[样本、原始证据与局限](live-reliability.zh.md)。

结构化交接已恢复约束、历史证据与下一步；后续重点是版本化领域证据和外部效果核对。当前 run 工具次数隔离和整体计划恢复已完成。其他原有待办仍以实际实现和测试为准。

已增加人工显式开始的持久任务队列、单 worker、独立执行记录与聊天进度投影；待执行记录跨重启保留，未知领取不重放，排队暂停/取消优先。[执行契约](protocol.zh.md#独立任务执行)记录边界。

每轮任务现在重建独立于滚动摘要的结构化交接（schema 1）：目标、验收、预算、工作目录、计划版本、历史测量、近期步骤与交付物位置。历史记录明确不是当前核验；内容损坏、跨执行上下文或超过 64,000 字节时停止，不静默删约束。

已补待核对状态清空心跳后的恢复护栏：恢复和新回合都检查确切 run 的未知调用，不能绕过旧断点。前台 exec 的超时/输出读取失败/无退出码终止也进入结构化不确定停止；终止进程不代表撤销已发生效果。

任务与目标的状态和投递生产记录已原子提交（migration 0029）；失败不会提前通知完成，入队失败和重启可重试，端点变更不自动转投。故障注入覆盖了 SQLite FAIL 事务回滚、完成提交失败以及投递端点隔离。

定时任务已补原子领取与不可变结果（migration 0030）：未知领取不重放，漏触发才补跑；文件和通知投递从持久结果恢复，冲突不覆盖人工文件。核对后可用 `joy schedule acknowledge <name>` 释放旧领取。

轮次编号随执行 checkpoint 原子提交（migration 0031），恢复以 checkpoint 编号为准，不因旧任务计数获得额外轮次；轮次记账失败停止执行。

交接按明确 turn/run 绑定查找，歧义绑定拒绝执行。规划／模型调用前严格校验持久约束；恢复先记入已知 checkpoint Token 用量再检查预算。完整 `just check` 曾在 0032 记忆修复后通过；后续身份与准入改动仍须完成新的集成检查。

执行终态的任务、准确 run 与回执共同提交；回执使用真实 run id 而非假定与 turn id 相同（migration 0034）。

外部输入等待已接通协议、TS/Python SDK 与驾驶舱：不可修改条件、幂等定向事件、草稿检查点、同一次执行恢复，以及持久化人工暂停优先。迁移 0035/0036；人工继续将授权、任务状态和重新打开的检查点原子提交。来源字段仅用于关联，仍依赖鉴权宿主。

逐操作日志与人工核对现已贯通循环检查点、迁移 0037、鉴权宿主协议、生成的 TS/Python 客户端及驾驶舱。意图、结果和检查点原子提交；不可修改的人工证据修复确切未决工具结果，不执行也不恢复任务。人工回执不满足实际工具成功次数。已停止的旧检查点现可重建明确标记来源的操作元数据，不改写原会话、不启动执行。服务端幂等键、无任务回合核对和更强领域验收仍是明确后续项。

文件验收现记录实际观察字节的摘要，并将版本化验收回执和检查投影原子提交。完成回执绑定确切 run 的验收；读取时拒绝内容或时间被篡改的回执。证据持久化失败阻止完成。这覆盖文件版本，不等于领域真实性或远端回读验证。

生产入口在迁移/恢复前统一取得内核持有的数据库执行锁。Server 副本与后台作业结算保留所有权；跨进程崩溃及竞争启动测试覆盖释放/拒绝路径。这不代表跨会话共享工作区写入已经串行化。

记忆提炼上下文与事实原子写入，保存聊天行引用和摘要，相同上下文重试不重复增加确认次数（0039）。人工有效期过滤事实召回；静态页面含有有界、缺失或已更正来源时，读取时退出自动召回（0040）。没有生成记录的人工页面不能被覆盖。事件历史、语义改写抑制和自动临时状态分类不在此保证内。


运行时修改准入已跨会话工具表副本串行化文件、执行、声明式命令与未知 MCP 副作用。后台进程保留许可到结算，查询与取消保持可用；忙碌准入有界且可见。覆盖协作会话/作业重叠，不覆盖不同 home、人工编辑器或远端服务冲突。

主模型配置现可声明函数工具能力、上下文估计与 Responses 推理力度。无效声明在写入凭据前拒绝，不支持工具的请求在调用供应商前停止。原生接续保持不丢失，力度不会串到另一个小模型。自动能力探测、托管工具和外部 harness 对照仍为独立后续项。
结构化文档验收现可在经过校验的 RFC6901 路径上比较有类型的 JSON 值，使用固定期望值和有界读取。回归场景拒绝正文藏有正确数字、字符串/数字混淆和缺失字段冒充 null，并沿用版本化回执绑定测量。这是本地合同符合性，不是外部领域事实证明。
扩展真实模型证据现覆盖明确的中文连续性与过期记忆召回。等待输入、独立聊天、交付样本在同一 run 中完成且只写入一次最终文件；保留记录需离线纠正把草稿也算入的计数器。此前四步样本安全停在待处理状态。四次运行合计 45 次请求，高峰价估算 ¥0.198044，保守预留 ¥3.819316，在 ¥10 内。原始失败、复核来源及未测质量见真实可靠性报告。
普通聊天已补人工查询/核对、逐操作快照绑定、不可变证据和同会话读取工具限制。新消息不能绕过未知效果，覆盖启动未领取边界及旧元数据缺口。记录证据后旧回合仍停止，新指令使用当前工作目录。任务核对继续保留确切最新 run 护栏；SDK 与驾驶舱复用宿主规则。

真实进程 SIGKILL 测试已覆盖工具发出前、外部效果已提交但未确认、工具结果已持久化三个边界，并比较不中断基线（`just smoke-recovery`）。恢复因未知结果或缺少配置而停止前仍计入原生检查点已知用量；重复恢复沿用轮次水位，保留人工暂停。未记录的供应商用量和活动时长仍是近似值。

快答现可在本会话近期上下文与 SOUL 之外读取有限已存个人偏好，不增加模型调用。历史来源标签附有明确的不确定性说明，不冒充人工核验；删除、更正、有效期与推断过滤均沿用存储规则。分类提示将情绪/关系支持优先交给完整路径，真实质量仍待评测。

临时观察现保留用户角色原文、未经校准的模型置信度及来源时间有效期（0041）；提炼使用类型化 facts/states，结构不合法时保留来源重试。持久来源批次和事件上下文回执（0042）让中断恢复不混入新聊天、不重复写相同批次摘要。记忆 worker 保留运行时所有权，关闭时取消并等待停滞调用退出。历史未标记领取、语义分类质量及事件历史脱敏仍有明确限制。
