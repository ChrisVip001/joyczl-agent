# Joy Harness 改造实施报告

[English](harness-implementation-report-2026-11-14.md) | 简体中文

日期：2026-11-14。范围：自 2026-11-12 架构评估以来，在本会话持续实施的改造。

**结论：可靠性底座和一条合成的任务交付闭环已大幅补齐，但原报告没有全部完成。最新记忆改动之后的最终全量检查和端到端回归现已通过；但发布审查、真实领域闭环及质量验证尚未完成，不能称为已经证明能长期可靠托管真实事务的个人管家。**

## 1. 已经实施了什么

已完成最初的架构评估、优先级与退出条件报告，并按授权初始化了 CodeGraph 索引。后续工作保留原技术底座，逐步落实下列改造。

| 方向 | 已实施的具体能力 | 解决的问题与边界 |
|---|---|---|
| 副作用与恢复 | 工具执行前持久化意图；逐操作台账；结果未知时停止；人工核对绑定确切操作和断点摘要 | 避免断线或重启后盲目重放；人工回执不会冒充实际工具成功。任意远端服务仍无通用恰好一次保证 |
| 统一任务推进 | 新执行与恢复共用任务驱动、预算、验收和收尾；严格绑定 task/run/turn；持久化轮次与累计用量水位 | 恢复不再只接续聊天而绕过任务验收；重复恢复不重复计入已知 token |
| 停止路径记账 | 未知结果、缺少模型配置等提前停止路径仍计入检查点已知用量；记账失败保留证据并要求关注 | 已复现并修复“检查点有 15 token、任务却显示 0”的问题。未收到或未保存的供应商用量仍无法精确还原 |
| 独立任务 | 人工开始的持久任务队列、单 worker、独立执行记录、本会话进度投影 | 聊天和长任务有各自上下文；没有让模型自行授予任务执行权限 |
| 等待与唤醒 | 后台作业关联任务；声明外部输入条件；定向事件、去重、恢复；持久人工暂停优先 | 可以生成草稿、等待数据、期间聊天、收到输入后续作；来源字段本身不是外部鉴权 |
| 完成与交付 | 任务/目标完成回执与状态原子提交；持久 outbox；失败重试；定时任务结算与投递记录 | 重投递不重新跑模型；通知失败保留记录。尚未证明真实外部渠道端到端可靠性 |
| 验收与证据 | 文件字节摘要、版本化核验回执、确切 run 绑定；有类型的 JSON 指针/值比较；未核验产出单独标记 | 不再仅凭正文出现某个数字或模型自称完成判断成功；仍不能证明研究结论、业务数字或远端结果真实 |
| 执行所有权与冲突 | 同一规范化数据库的内核锁；运行时/后台作业持有所有权；跨会话工具修改协调；后台命令保留修改许可至结算 | 防止两个运行时同时恢复同一数据库；不是分布式锁，也不隔离人工编辑、不同 home 或远端资源 |
| 普通聊天未知操作 | 人工查看/核对接口、TS 客户端、驾驶舱入口；同会话后续聊天的修改围栏 | 不能通过新开一轮聊天绕过旧的未知效果；记录核对后旧轮次仍停止，需新指令使用当前工作目录 |
| 结构化交接 | 每轮从任务合同、计划、步骤和交付物重建交接；完整不可变计划版本；损坏或越界停止 | 长任务关键约束不再仅依赖滚动摘要 |
| 模型适配 | 原生 Responses 的文本、图片、函数工具、SSE、加密接续；DeepSeek 思考接续；模型工具能力、上下文和推理力度配置 | 明确不支持的请求在本地拒绝；尚未覆盖自动能力探测、托管工具、WebSocket 引导和 API 异步工具 |
| 聊天连续性 | 快答保留本会话近期内容、SOUL、有限已存个人/交互偏好；中文技能发现；情绪/关系支持路由提示优先完整路径 | 不增加快答模型调用；历史 source=user 可能由工具写入，不能当成人工核验。情绪支持质量尚未测量 |
| 记忆纠错与时效 | 删除/更正抑制、提炼上下文摘要、有效期；召回过滤失效事实；静态页来源校验；保护未受管理的人工文件 | 防止完全相同的旧声明自动复活；语义改写、旧数据和原始历史的擦除尚不完整 |
| 临时状态记忆 | 将长期 facts 与临时 states 分开提炼；核对用户角色原文及来源摘要；模型自报置信度；从原消息计算 1–24 小时有效期 | 重试不续期，过期来源不产生临时事实，人工修改优先。引文匹配和置信度不等于语义判断正确 |
| 记忆提炼生命周期 | 持久领取批次与完成标记；恢复保留原来源集合；退避事务；事件摘要来源回执；worker 持有所有权并在关闭时取消/等待调用退出 | 修复已领取对话被永久跳过、重复摘要、关闭后调用继续运行等问题；迁移前没有标记的旧领取不能自动识别 |
| 工程交付 | 数据库迁移、生成协议、TS 客户端、驾驶舱核对界面、确定性/进程级测试与双语文档同步 | 不是只改提示词或写设计文档；最新整包回归已通过，发布整理仍未完成 |

主要实现记录见 [持续实施清单](harness-upgrade.zh.md)，接口边界见 [协议](protocol.zh.md)。本轮涉及的新增迁移延续至 `0042_consolidation_claims.sql`。

## 3. 真实模型评测与费用

使用用户已有主力配置 **ds / DeepSeek / deepseek-flash**，没有另选付费模型。模型记录是请求别名，不证明锁定了服务商内部某个后端版本。

- 十二次调用评测程序，共 **90 次逻辑模型请求**。
- 记录输入 **112,803 tokens**、输出 **20,172 tokens**。
- 按当时官方高峰价估算 **¥0.386982**；保守请求预留累计 **¥7.573676**。预留不是实际花费，估算不是账单核销；均在授权 **¥10** 范围内。
- 已覆盖小样本对话连续性、中文连续性、文件交付、未知效果停止、过期记忆，以及等待输入期间聊天后交付的合成场景。
- 保留了失败记录：一处状态名断言错误、一处等待样本步数不足、一处把草稿误算为重复最终写入。最后一项经保留回执离线复核确认运行时交付成功，**不是另一次成功模型运行**。
- 临时状态提炼新增一个真实模型结构性样本通过：只持久保存称呼、疲惫按来源时间限期保存。该样本不评情绪支持质量；快答和提炼崩溃恢复没有新增真实模型质量评分。尚无独立陪伴质量评分、长研究质量评分或真实跨日托管成功率。

原始记录、复核来源和费用口径见 [真实模型评测报告](live-reliability.zh.md)。


公开资料研究新增三次调用：首次正常读取与交付通过；通用写入反向样本失败——来源不可用时状态正确停止，却生成了部分最终文件。随后受控发布适配器的正反样本均通过：只有两份来源回执、精确引文与类型事实齐全才发布；来源缺失不生成文件。失败原记录保留。这是评测器内受限 MCP 领域适配器，不是生产通用写入的新保证，也未验证失败说明文案的质量。详见[研究报告](public-source-research-2026-11-14.zh.md)及[原始正反记录](../evals/results/deepseek-flash-2026-11-14-research-guarded.json)。

中文陪伴新增真实样本与[来源复核](../evals/results/analysis/support-review-2026-11-14.json)：原始 DSML 失败保留；已修复空工具表仍宣称可用搜索的提示不一致，并收紧格式指标。早期复测形式通过仍有记忆声称问题；加入共用约束后的新样本明确承认缺少历史，双轮字面连续性也通过，但情境补写和可用性措辞问题仍保留，不能据此宣称整体陪伴质量通过。

## 5. 建议接下来的顺序

最终全量验证、固定来源研究试验及证据归档已完成；[审查与恢复指南](harness-release-review.zh.md)已整理。用户已完成模块拆分提交，本轮后续修正仍未提交。下一阶段优先多步骤任务执行、中断后交付、长研究与具体事务的远端验收；日常对话作为辅助能力。外部 harness 对照应在同一任务集与工具合同稳定后开展。

这轮保留了 Rust、SQLite、本地优先和单一协议，没有迁入新的大型 agent 框架。也没有实现分布式调度、大规模多 agent 或全面插件化；这些原本就是报告建议暂缓的方向。

## 6. 工具与记录限制

报告依据实施记录、保留评测文件和本会话已观察到的工具结果。工作区还存在其他改动，不将整棵工作区差异全部归为本次成果。

CodeGraph 查询的自动审批审核曾因账户用量上限失败，查询未执行；工具明确说明这不是安全判定。该工具随后不再可用。这与 DeepSeek 评测的 ¥10 费用计量不同。

## 长任务可靠性补充

产品主线是完成复杂长任务，日常情感对话仅为辅助。修复了必要步骤或产物证据写入失败后仍可能完成任务或续轮的问题：现在保留已知消耗并停止等待处理，修复存储后可幂等补记，不重复执行实际操作。也修复了人工明确继续已停止检查点被拒绝的问题；取消任务、过期执行和未知效果仍受原有围栏约束。

最终完整门禁通过：Rust 939、前端 113、确定性 70、回放 5，Clippy 零警告。长任务本地脚本基准从 8/11（恢复 0/3）修正为 11/11（恢复 3/3）：既补齐测试脚本的人工恢复动作，也修复运行时恢复条件，原验收断言未放宽；初始失败记录保留。这不代表真实模型开放任务成功率提高。另有五个真实 SIGKILL 场景通过；此项与基准中的进程内运行时重建分开记录。本轮没有新增付费模型调用。见[验证摘要与来源摘要](../evals/results/task-reliability-validation-2026-11-14.json)。长研究质量、跨日真实事务及独立评审仍待完成。
