# Joy Web 设计系统（DESIGN.md）

> Joy 驾驶舱的设计规格。风格基调：**暗色优先的克制工作台**——参考 Linear 的暗色工程
> 美学（亮度分层代替阴影、半透明白细线做结构），唯一的彩色是品牌紫。所有值以 token
> 形式落在 `style.css` 的 `:root`，组件只允许引用 token，不许出现裸色值。

## 1. 气质与原则

- **暗色是原生介质**，不是亮色主题的反色。层级靠「亮度的细微台阶」表达：
  背景 → 面板 → 浮层，每层只比下层亮一点。
- **克制单色 + 唯一强调色**：界面近乎单色，紫色只出现在主操作、活动态、品牌元素上。
  状态色（绿/红/琥珀）只用于状态本身，不做装饰。
- **大留白**：聊天主区单列居中（max-width 760px），信息密度靠排版层级而非边框分隔。
- **细线结构**：边框一律 `rgba(255,255,255,0.05~0.10)` 的半透明白，暗色下不用实色边框。
- **微动效**：淡入、呼吸点、150–250ms 的 ease-out 过渡；不弹跳、不抢戏。

## 2. 色彩 Token

### 表面（暗色，默认主题）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#0c0d10` | 页面画布 |
| `--bg-panel` | `#14161b` | 侧栏 / 抽屉面板 |
| `--surface` | `rgba(255,255,255,0.03)` | 卡片、输入框底 |
| `--surface-hover` | `rgba(255,255,255,0.06)` | 悬停态 |

### 表面（亮色，`@media (prefers-color-scheme: light)`）

| Token | 值 |
|---|---|
| `--bg` | `#fafaf9` |
| `--bg-panel` | `#f1f1ef` |
| `--surface` | `#ffffff`（带细边框 `#e5e4e0`） |

### 文本

| Token | 暗色 | 亮色 | 用途 |
|---|---|---|---|
| `--text` | `#e8e9ec` | `#1a1c20` | 主文本（不用纯白） |
| `--text-2` | `#9ca0aa` | `#5c5f66` | 次要文本、正文辅助 |
| `--text-3` | `#6e727c` | `#8b8e95` | 元数据、时间戳、占位 |

### 品牌与状态

| Token | 值 | 用途 |
|---|---|---|
| `--accent` | `#7c5cff` | 主操作、活动态、链接（唯一彩色） |
| `--accent-hover` | `#9d85ff` | 强调色悬停 |

### 边框与线

| Token | 值 |
|---|---|
| `--line` | `rgba(255,255,255,0.08)` |

## 3. 字体

- 栈：`"Noto Sans SC", "PingFang SC", system-ui, -apple-system, "Segoe UI", sans-serif`
- 等宽：`ui-monospace, "SF Mono", Menlo, monospace`（代码、命令、路径）
- 正文 **14px / 1.65**；辅助 13px；元数据 12px；会话标题 15px/500
- 权重只用三档：400（阅读）、500（强调/导航）、600（标题/按钮）
- 不使用粗体 700；标题不加字距，正文不加负字距（中文无此需求）

## 4. 间距与圆角

- 基数 8px；实际使用 4 / 8 / 12 / 16 / 24 / 32
- 圆角：控件 8px；卡片 12px；大浮层 16px；胶囊 999px
- 阴影：暗色下靠亮度台阶而非阴影；浮层用
  `0 8px 32px rgba(0,0,0,.45), 0 0 0 1px var(--line)` 双层

## 5. 组件速查

- **主按钮**：`--accent` 底、白字、8px 圆角、hover `--accent-hover`
- **幽灵按钮**：`--surface` 底 + `--line` 边、`--text` 字
- **胶囊 chip**：透明底 + `--line` 边、12px、事件分类色仅点在左侧圆点上
- **消息流**：单列；用户消息右对齐浅底块（`--surface`），agent 消息通宽无框——
  agent 是「页面本身在说话」，不用气泡包住它
- **活动时间线**：消息上方的细线轴 + 分类圆点 + 一行摘要；默认收起为最新一条，
  展开看全部（参数摘要、耗时、状态点）
- **任务卡 / 授权卡**：12px 圆角浮层卡，`--surface` 底 + `--line` 边；授权卡带
  `--warn` 左缘与呼吸点
- **输入区**：单块圆角容器（textarea + 附件 + 发送），聚焦时边框转 `--accent`

## 6. 布局

- 桌面：左栏 232px（品牌 / 会话列表 / 面板入口）+ 主区（聊天单列居中）；
  面板抽屉从右滑入（fixed，宽 min(420px, 92vw)），不挤压聊天列
- 移动（<720px）：侧栏收成顶栏，抽屉全宽；触控目标 ≥ 40px

## 7. Do / Don't

- ✅ 引用 token；亮度分层；半透明细线；主区留白；事件分类用「点 + 灰字」
- ❌ 纯黑 `#000` / 纯白 `#fff` 文本；彩色大底块；实色粗边框；卡片套卡片；
  渐变横幅；弹跳动画；每按钮都做成主按钮
